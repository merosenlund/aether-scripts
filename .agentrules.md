# Aether Scripts Agent Rules

Agents working on this repository must strictly adhere to the following rules:

## 1. Testing & Code Quality

- **Always write tests**: Every new feature, utility, or component must have accompanying tests.
- **Strict Linting**: Ensure zero linting errors before considering a task complete. Follow all configured ESLint/Prettier rules strictly.

## 2. Programming Paradigm

- **Functional Programming**: Prefer functional programming patterns where possible. This is highly desired to enable better testability, predictability, and to avoid side effects.

## 3. UI, HTML, & Components

- **Data-Component Attribute**: **All HTML elements** must include a `data-component` property that specifies their purpose and differentiates them.
  - _Crucial Rule_: This `data-component` property MUST be included **before** the `class` property in the HTML definition.
  - Example: `<div data-component="journal-entry-card" class="p-4 bg-white rounded-lg shadow">...</div>`
- **Styling**: Use Tailwind CSS for all styling.
- **Component Library**: Use `shadcn-svelte` for prebuilt components to reduce custom boilerplate. Ensure they are styled appropriately and include the required `data-component` attributes where applicable.

## 4. Technology Stack Context

- **Frontend**: SvelteKit, TypeScript, Tailwind CSS, shadcn-svelte.
- **Backend/Runtime**: Deno, Deno Deploy.
- **Database/Auth**: Supabase.
